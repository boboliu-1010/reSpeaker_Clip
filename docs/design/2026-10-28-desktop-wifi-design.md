# 桌面原生 Wi-Fi 配网与网页扫描收敛

用户选择：桌面原生提供 Wi-Fi 列表/匹配/密码保留和显示隐藏；网页移除 Mac 扫描入口，保留手填配网、状态、测试、录音及固件功能。

桌面 Clip 页在未连接设备时即可显示配网表单并扫描 Mac 附近网络。连接后读取 NETCFG 的设备 SSID，优先设备配置；手动编辑后刷新不覆盖草稿。使用现有原生 `boa_voice/wifi` 通道直接扫描，不经过 HTTP 助手。规则沿用已验收方案：同名优先2.4GHz/WPA2，兼容项优先、按信号排序；当前Mac网络兼容且无其他输入时默认选中，否则保留Clip/手填目标；不兼容项显示原因且禁选。

ClipUploadPanel始终挂载，at可空，密码仅留在本页控制器；保存、失败、扫描、名称修改、断连重连不清空。显示/隐藏只切换obscureText，默认隐藏。连接后保存需回读同一SSID、确认持久化，再执行NETCHECK；结果绑定job，历史成功不当实时在线或Server可达。

设备命令串行：父页操作和面板操作互斥；原生扫描也禁用冲突控件。异步扫描/读配置捕获设备与编辑版本，过期结果不得覆盖新连接或草稿。没有Clip时禁用保存/检测而保留扫描、选择和输入。

网页移除Mac扫描/下拉选择/UI导入，CSP恢复仅同源连接。桌面入口停止启动19529回环助手。既有其他Web功能和权限保留；不改固件、不部署、不打DMG、不自动提交原待合并工作。

测试：Dart真实匹配规则、widget扫描/选择/密码保留、无Clip按钮限制、连接读配置/保存失败与成功、状态job与断线；Node回归及Server网页CSP；本机构建启动、桌面实扫和网页无需桌面扫描依赖。实体Clip本轮不可用，明确标待实测。
