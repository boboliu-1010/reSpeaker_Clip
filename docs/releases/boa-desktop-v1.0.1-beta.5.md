# Boa Voice 1.0.1-beta.5

本版修复与 Clip 建立 BLE 连接时的错误恢复及 Apple 平台配对等待，沿用原有 GATT UUID 和协议，不要求配套修改固件或 Server。

## 修改

- 扫描连接与按 ID 重连统一走底层连接初始化。服务发现、特征缺失、通知订阅等步骤失败后，主动断开原生 BLE 连接并释放 MTU 监听，避免下次重试复用半初始化连接。
- Apple 平台 CCCD 返回认证不足（5）或加密不足（15）且仍保持连接时，最多尝试 8 次，间隔 700ms，等待系统配对完成；其他失败保留原有最多 3 次规则。未降低加密要求、未清除设备配对信息。
- 一个连接复用一个 AT transport 和串行队列。桌面使用 SDK 的验证连接接口，必须收到有效 GSTAT 响应后才开放控制；验证失败则断开。
- Mac 与 iOS 扫描前都等待蓝牙就绪；关闭、拒绝授权、不可用、初始化超时分别结束操作。
- 桌面接入连接阶段日志，关闭底层逐包 debug 输出；不打印原始 AT 负载或文件内容。

## 验证范围

连接回归使用原生平台事件夹具，运行真实 flutter_blue_plus 服务发现、CCCD、连接状态和 SDK/AT 实现，覆盖失败清理、重新建链、配对延迟、永久失败的重试上限、AT 通道复用、真实响应验证及无响应断开。

- SDK 全套：71 项通过；SDK 和桌面改动的定向静态分析无问题。
- 桌面/存储：38 项通过。独立代码审查未发现阻塞项，并单独复跑 12 项 BLE 回归通过。
- App 全套：40 通过、1 失败。失败是旧 `widget_test.dart / App boots smoke test`；此前在未修改 SDK 时复跑该用例也失败，不属于本次 BLE 回归。未将其记为通过或跳过。
- macOS Release 构建成功。
- Universal DMG 校验、只读挂载、复制后的签名验证通过；45 个原生二进制依赖检查通过。复制版已启动进入主界面并连接原有 Server。
