# 网页默认连接当前 Boa Server

用户确定：网页打开后自动连接当前 Boa Server，先处理网页；Clip 真机上传暂缓。

页面使用 location.origin，同源检查服务，展示“正在连接 / 已连接，请登录 / 连接失败”；支持重试和浏览器恢复联网后的检查。“连接服务”按钮改为“登录”，登录后显示用户身份。服务连通与用户授权独立，不保存令牌到浏览器存储，不修改设备配置。

使用最小公开接口 `GET /api/boa/v1/health`，仅返回 `service=boa`、`status=ok`，避免把鉴权失败当健康检查；原有登录协议保持。健康检查不表示 Clip 联网或上传成功。

验收：首次自动检查、失败、超时、重试、旧请求不覆盖新登录状态、未登录无法访问录音；在远程 9529 验证。

用户追加要求简化使用：主入口使用“选择凭证并登录”，选文件后自动登录；保留折叠的手动登录。上传地址、设备 ID 和设备令牌放到默认关闭的高级设置，普通使用只需连接 Clip、配 Wi-Fi（已有配置无需重填）、查看录音。不会自动认领设备或替换身份凭证。

日常页面以录音为主，Wi-Fi 设置默认折叠；固件指标移入固件库，OTA 提示移入设备升级区，功能不删除。
