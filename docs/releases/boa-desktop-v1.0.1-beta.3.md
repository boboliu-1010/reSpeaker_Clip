# Boa Voice 1.0.1-beta.3（本地验收中）

分支：`boa/desktop-beta3`。本版本用户安装确认前不上传 Release。

## 新功能

- 录音：系统输入设备选择、电平显示、暂停/继续、停止后命名保存；取消保存及重启后暂存恢复。
- 文件：详情（类型、时长、大小、入库时间、来源、保存位置）、本地重命名、系统保存对话框导出、回收站与恢复。导出校验字节；禁止覆盖应用私有数据。本地回收不删除服务器文件。
- 同步：手动上传独立于自动开关，按文件重试；任务列表显示目标、进度、错误与等待状态。保留 HTTP 分片、续传及 SHA-256 校验。
- Clip：根据已有 VERSION/GSTAT 响应显示录音状态、电量、充电、固件、时长（秒）、剩余空间（MB）。未知字段保持未知；保留原始响应供排查。

## 使用

1. 安装后原有音频及服务配置保留。在“服务设置”刷新并选择麦克风。
2. 点击“麦克风录音”，停止后填写名称。取消会保留暂存文件，可点击“恢复录音”再次保存。
3. 点击本地音频查看详情；右侧三点菜单可改名、导出或移入回收站。“回收站”中可恢复。
4. 自动上传关闭时，可点击文件旁云上传按钮，进度与失败原因见“同步任务”。不同服务器的任务等待连接原服务器，不会改投新目标。
5. Clip 需真实硬件连接后刷新状态。此轮未实现桌面 Clip 文件下载、Wi-Fi 同步、OTA 或模型转写。

## 验证与边界

验证过程与最终结果见 `docs/product/desktop-beta3-verification.md`。旧手机端 smoke 测试缺少 ProviderScope，属于现有测试夹具问题；不代表桌面启动失败。

此版本保留 App Sandbox，采用临时本地签名、未公证。通过浏览器下载后仍可能需用户亲自在“系统设置 → 隐私与安全性 → 仍要打开”确认；本地构建运行不能代替下载后的 Gatekeeper 验证。
