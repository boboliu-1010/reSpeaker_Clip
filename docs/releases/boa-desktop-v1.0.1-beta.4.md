# Boa Voice 1.0.1-beta.4

## 功能

- Clip：BLE 配网、设备上传目标与凭证、时间同步、自动上传开关、Wi-Fi 检查、上传进度与取消；保留设备连接、状态、开始/停止录音。
- 音频：保留麦克风录音、本地管理/播放、自动上传和下载；服务器列表展示 App/Clip 来源、时间、大小。Clip 原件可导出。
- Server：同一服务提供 HTTPS 与 DTLS，用户数据独立，支持上传续传和完整性校验、设备换绑隔离、索引恢复。
- 配置：可导入开发 CA，保持 TLS 与主机名校验；账户隔离续传/备份缓存，配网凭证脱敏。
- 修复：避免复用已经被 Server 回收的 HTTP 连接，防止界面空闲后点击下载失败。

## 验证

- Server 与既有存储：20 项测试通过；独立审查复核。
- DTLS 接收/发送核心：21 项通过，包括实际加密握手、重连及恢复，无跳过。
- Flutter 桌面/存储测试：38 项通过，含失效连接回归；目标静态分析无问题。
- 开发机 HTTPS：64 MiB WAV 真实上下行及 SHA256 校验通过；用户隔离实测通过。
- 2026-10-26 补测：Mac 到开发机 UDP 9528 的 DTLS 上传、落盘回执及 HTTPS 查询/下载连续 3 次通过，详见[测试记录](../testing/2026-10-26-udp-9528.md)。
- DMG 校验、复制后启动、服务连接、45 个原生二进制的依赖检查和签名验证通过；下载后的合成音频已验证原生播放。
- 新签名安装版麦克风请求停在系统授权处；超时提示正常，授权后的实际录音尚未验收。

## 使用

将 DMG 内 Boa Voice.app 拖到 Applications。开发机地址 https://100.58.19.213:9528，用户凭证由开发者交付。在服务设置导入开发证书后连接。Clip 设备凭证与用户凭证分开。

本地临时签名，未经 Apple 公证，首次可能需要在隐私与安全性中手动确认。真机 BLE、配网及上传后清理仍需实际 Clip 验收。
