## 如何测量

1. SSH：先分别以 8 MiB 探测上下行，再选择正式文件大小；使用预先生成的不可压缩随机字节，显式 `Compression=no`，复用一个 SSH 连接。上传计时覆盖发送至远端落盘 fsync 与长度确认，下载覆盖接收至本地 fsync。每次完成后单独核验 SHA-256 和长度，不把整文件哈希计算计入传输耗时。没有使用 SSH 端口转发。
2. HTTP：在远端对实际运行的 `boa-audio-storage.service`、`127.0.0.1:18765` 发请求。客户端读取文件和计算分片哈希在计时前完成；上传只计各 PUT 的传输与确认，合并/完成等待单独记录。下载从 GET 发出计至 EOF 和落盘 fsync，随后在计时外核验文件 SHA-256。未执行音频解码。
3. 两组顺序执行，未让测速任务互相争用资源；正式样本各 3 轮，全部字节数和哈希通过。HTTP 使用热缓存、单客户端，不是并发/长时间容量或冷盘测试。
4. SSH 测量脚本保留在本 Mac `~/.cache/boa-voice/speedtests/measure-ssh.py`，使用已有 Python 3.13 venv；结果目录见 SSH JSON。HTTP 脚本保留在远端 `~/apps/boa-voice/verification/2026-10-22/measure-http-throughput.py`，使用服务 venv Python 3.12；各次原始记录见下方 JSON。
